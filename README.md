# Online Book Store SQL Project

## 📌 Project Overview

A PostgreSQL database project designed to analyze an
online book store's books, customers, and orders.

## 🛠️ Tools & Technologies

- PostgreSQL
- SQL
- CSV

## 🗄️ Database Tables

### Books
Contains book information including:
- Book ID
- Title
- Author
- Genre
- Published Year
- Price
- Stock

### Customers
Contains:
- Customer ID
- Name
- Email
- Phone
- City
- Country

### Orders
Contains:
- Order ID
- Customer ID
- Book ID
- Order Date
- Quantity
- Total Amount

## 📊 SQL Concepts Used

- SELECT
- WHERE
- DISTINCT
- ORDER BY
- LIMIT
- SUM()
- AVG()
- COUNT()
- GROUP BY
- HAVING
- JOIN
- LEFT JOIN
- COALESCE()

## 🔍 Analysis Performed

- Books by genre
- Books published after 1950
- Customers by country
- Monthly orders
- Total book stock
- Most expensive book
- Total revenue
- Books sold by genre
- Most frequently ordered book
- Top 3 Fantasy books
- Books sold by author
- Highest-spending customer
- Remaining stock after orders

## 🎯 Objective

To strengthen practical SQL and database analysis skills
through a real-world online bookstore scenario.
